# DELTA Studio — catálogo e ferramentas digitais

Demonstração pública de projetos e recursos gratuitos da DELTA. **Este repositório não contém downloads pagos, tokens, dados de clientes ou checkout.**

## Publicar no Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/idelta775-hash/delta-produtos)

O arquivo [render.yaml](render.yaml) prepara um Static Site. A implantação exige que o titular acesse sua conta Render, revise e confirme a criação do serviço.

- Tipo: Static Site (Render Blueprint `runtime: static`)
- Repositório: `idelta775-hash/delta-produtos`
- Branch: `main`
- Build: `sh render-build.sh`
- Diretório publicado: `render-dist`
- Atualização automática: inicialmente desligada. Pode ser habilitada após verificar o serviço.
- A URL final será fornecida pela própria Render; não está confirmada antes da implantação.

Leia [DEPLOY_RENDER.md](DEPLOY_RENDER.md) para instruções.

## Conteúdo

O site contém 7 páginas, 2 recursos gratuitos, 2 artigos educativos e imagens comerciais de 2 produtos originais: DELTA-PRICER-001 e DELTA-PRINT-001.

O build usa uma lista estrita de arquivos públicos e ajusta os endereços canônicos ao hostname real fornecido pela Render. **Não oferece pagamentos.** Links de compra somente após cadastro e aprovação do vendedor e validação do checkout.
